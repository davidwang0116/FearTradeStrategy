Why broad index beta

The index is the Sharpe-efficient core that most professionals fail to beat

Diversification (Lecture 9)

With n weakly correlated stocks, volatility falls like 1/√n while expected return holds, so Sharpe grows with breadth.

CAPM

A single stock’s Sharpe ratio is below the market’s: idiosyncratic risk is not paid.
